# Аналитика и дашборды (E6)

Metabase запускается через `docker-compose.yml` (порт 3000) и подключается к PostgreSQL.
Дашборды строятся поверх таблицы `events` (контракт §5) и витрин.

## Планируемые витрины (SQL) и дашборды
- TTFR (Time To First Response): медиана и p95.
- Lead capture rate, лиды по каналам/источникам.
- Automation rate vs. escalation rate.
- Воронка: лид → квалифицированный → сделка → выигрыш.

## Файлы
- `sql/` — определения витрин/материализованных представлений (добавляются в E6).
