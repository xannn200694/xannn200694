# Моки границ

Лёгкие заглушки на **Go 1.26** (стандартная библиотека), реализующие контракты из
`docs/03-interfaces.md`. Позволяют разрабатывать и тестировать эпики изолированно,
до готовности реальных сервисов.

| Мок | Контракт | Порт (compose) |
|-----|----------|----------------|
| `mock-llm` | §2 LLM Gateway | 9001 |
| `mock-rag` | §3 RAG Service | 9002 |
| `mock-crm` | §4 CRM Connector | 9003 |

Переключение сервисов на моки — через переменные `*_URL` в `.env` (например, `RAG_URL=http://mock-rag:8000`).
