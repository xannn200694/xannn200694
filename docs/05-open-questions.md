# 05. Открытые вопросы и допущения

В описании вакансии нет ряда деталей, критичных для реализации. Ниже — вопросы заказчику
(сгруппированы по приоритету) и допущения, принятые «по умолчанию», чтобы не блокировать старт.

## Блокирующие вопросы (нужно закрыть до Фазы 1)

1. **CRM:** какая CRM используется (amoCRM, Bitrix24, HubSpot, другая)? Есть ли доступ/тестовый аккаунт?
   Какова текущая карта полей и этапов воронки?
2. **WhatsApp:** какой провайдер/способ подключения (WhatsApp Cloud API, 360dialog, Twilio, Wazzup)?
   Есть ли верифицированный WhatsApp Business аккаунт и номер?
3. **Хостинг:** где разворачивать (облако/VPS, конкретный провайдер, регион)? Self-hosted n8n или Make SaaS?
   Есть ли требования к размещению данных внутри КГ?
4. **LLM:** какой провайдер предпочтителен (OpenAI, Anthropic, оба)? Есть ли бюджет/лимиты на токены?
   Ограничения по передаче данных за рубеж?
5. **База знаний:** где находится контент (сайт, документы, FAQ, скрипты продаж)? В каком формате?
   Кто отвечает за её актуализацию?

## Важные вопросы (нужно закрыть в Фазе 1)

6. **Языки общения** бота: русский, кыргызский, английский? Приоритет?
7. **Карта воронки продаж:** этапы, правила квалификации лида, SLA по времени ответа, правила эскалации.
8. **Тон и границы бота:** что бот может/не может делать (цены, скидки, обещания), когда обязателен человек.
9. **Объём/нагрузка:** ожидаемое число входящих в день, пики, число менеджеров.
10. **Часы работы менеджеров** для эскалаций (бот 24/7, а люди?).
11. **Существующие системы:** что уже есть (текущие боты, интеграции, таблицы), что переиспользуем.

## Юридические / организационные

12. **Персональные данные:** требования законодательства КГ к обработке/хранению PII, согласия клиентов.
13. **Доступы и владение:** на чьих аккаунтах создаются боты/интеграции, кому принадлежат ключи.
14. **Структура milestone'ов:** как заказчик хочет дробить оплату — совпадает ли с M0–M8 из плана?
15. **Приёмка:** кто и как принимает результаты этапа (критерии, тестовая среда, демо).

## Принятые допущения (по умолчанию, до уточнения)

> Эти допущения позволяют начать работу; при ответах заказчика план корректируется.

- Оркестрация — **n8n self-hosted** (приоритет вакансии).
- LLM — **OpenAI + Anthropic** через единый Gateway с абстракцией провайдера.
- Vector DB — **Qdrant** (альтернатива — `pgvector`).
- БД — **PostgreSQL**; аналитика — **Metabase**.
- Каналы — **Telegram** (старт) и **WhatsApp Cloud API** (после доступа).
- Деплой — **Docker Compose** на одном VPS на старте, reverse proxy с TLS.
- CRM — разработка против `mock-crm` по адаптерному интерфейсу до выбора конкретной CRM.
- Языки — русский на старте, мультиязычность закладывается архитектурно.
- Scope первого этапа — без телефонии/голоса, без мультитенантности (см. [`01-analysis.md`](01-analysis.md)).
