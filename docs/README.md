# План реализации проекта: AI-платформа автоматизации отдела продаж (Kivano)

Этот каталог содержит подробный план реализации проекта, восстановленный из описания вакансии
**«AI Automation Engineer / ИИ-Интегратор (Отдел продаж)»** (Kivano, ОсОО «Бизнес-процессы»).

План структурирован так, чтобы его можно было выполнять **параллельно несколькими агентами**: общая
архитектура и интерфейсные контракты зафиксированы заранее, а работа разбита на независимые потоки (эпики)
с явными зависимостями и контрольными точками (milestones).
