# Эпик E7 — QA, наблюдаемость и безопасность

**Цель:** обеспечить качество, надёжность и безопасность платформы; сопровождает все эпики.
**Можно стартовать:** параллельно со всеми.
**Milestone:** вклад в M8 (готовность к проду).

## Задачи
### QA / тестирование
1. Контрактные тесты для всех API из [`../03-interfaces.md`](../03-interfaces.md) (прогон в CI).
2. Интеграционные сквозные тесты ключевых сценариев (лид → ответ → CRM → аналитика).
3. Оценочные наборы качества для RAG/LLM (совместно с E1/E2).
4. Нагрузочное тестирование вебхуков (пики входящих, идемпотентность).

### Наблюдаемость
5. Централизованные логи (Loki/ELK), трассировка `trace_id` сквозь сервисы.
6. Метрики (Prometheus/Grafana): TTFR, ошибки интеграций, стоимость LLM, очереди.
7. Алерты: падение capture rate, рост ошибок, недоступность каналов/CRM, рост стоимости LLM.

### Безопасность
8. Верификация подписей вебхуков, защита эндпоинтов, rate limiting.
9. Управление секретами (нет секретов в репозитории; `.env`/секрет-стор).
10. Обработка PII: минимизация хранения, шифрование, политика хранения, соответствие законодательству КГ.
11. Резервное копирование PostgreSQL и конфигов n8n, проверка восстановления.

## Критерии приёмки
- CI прогоняет контрактные и интеграционные тесты.
- Настроены дашборды наблюдаемости и базовые алерты.
- Вебхуки защищены, секреты вынесены, бэкапы работают.

## Зависимости / контракты
- Сопровождает все эпики; зависит от их API и схемы событий.
