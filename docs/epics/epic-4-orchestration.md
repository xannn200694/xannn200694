# Эпик E4 — Оркестрация и воркфлоу (n8n)

**Цель:** превратить хаотичные ручные действия отдела продаж в чёткие автоматические сценарии воронки.
**Можно стартовать:** каркас — после E0; полноценно — по мере готовности E1/E3/E5 (на моках до этого).
**Milestone:** M5.

## Задачи
1. Развёртывание n8n (self-hosted, Docker, из E0), настройка вебхуков и креденшелов.
2. **Воркфлоу «Новый лид»:** входящее сообщение → создание/поиск контакта → автоответ через LLM → запись в CRM.
3. **Воркфлоу «Квалификация»:** сбор недостающих данных, lead_score (через `POST /v1/classify`), маршрутизация.
4. **Воркфлоу «Эскалация»:** при `should_escalate` — назначение менеджера, уведомление, постановка задачи.
5. **Воркфлоу «Напоминания/follow-up»:** расписания, повторные касания, при отсутствии ответа.
6. **Воркфлоу «Обновление сделки»:** смена статусов, заметки, синхронизация с CRM (E5).
7. Обработка ошибок: ретраи, dead-letter, алерты в E7.
8. Экспорт воркфлоу в репозиторий (`n8n/workflows/*.json`) для версионирования и ревью.

## Критерии приёмки (M5)
- Заданные сценарии воронки отрабатывают автоматически end-to-end (на staging).
- Эскалация и follow-up работают, ошибки ретраятся.
- Воркфлоу версионированы в репозитории.

## Зависимости / контракты
- Потребляет: Channel Gateway (E3), LLM Gateway (E1), CRM Connector (E5), `events`.
- Производит: автоматизированную бизнес-логику воронки.
