# n8n — оркестрация воронки (E4)

Self-hosted n8n запускается через `docker-compose.yml` (порт 5678). Воркфлоу версионируются
в каталоге `workflows/` (экспорт JSON) для ревью и переноса между средами.

## Планируемые воркфлоу (эпик E4)
- `new-lead` — новый лид: контакт → автоответ (LLM) → запись в CRM.
- `qualification` — квалификация и lead_score (`POST /v1/classify`), маршрутизация.
- `escalation` — эскалация на менеджера при `should_escalate`.
- `follow-up` — напоминания/повторные касания по расписанию.
- `deal-update` — синхронизация статусов сделки с CRM.

## Импорт/экспорт
- Экспорт: в UI n8n → Workflow → Download → сохранить JSON в `workflows/`.
- Импорт: n8n → Import from File.

> JSON-файлы воркфлоу добавляются по мере реализации E4.
