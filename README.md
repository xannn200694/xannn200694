# AI-платформа автоматизации отдела продаж (Kivano) — план реализации

Репозиторий содержит **план реализации проекта**, составленный на основе анализа вакансии
*«AI Automation Engineer / ИИ-Интегратор (Отдел продаж)»* (Kivano).

Проект: ИИ-ассистенты для WhatsApp/Telegram (ответы по базе знаний 24/7), автоматизация воронки
продаж в n8n, интеграция с CRM и сквозная аналитика.

План структурирован для **параллельного выполнения несколькими агентами** — см. [`docs/`](docs/README.md).
